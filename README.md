# 🌌 HalDo AI OS - Das kosmische Betriebssystem

**Entwickler:** Halil Donma (HalDoaios-Official)
**Projekt-Name:** HalDo AI OS, HalDo AI Cyborg OS, HalDo CYBORG AI OS
**Technologie:** Reines HTML, CSS und JavaScript (Canvas API für 3D-Universum)

## 🎯 Das Ziel
Ein professionelles, lebendiges Betriebssystem im Browser, das auf allen Geräten läuft. Es kombiniert ein 3D-Planetensystem mit einer AI-Präsenz (Cyborg) und einem voll funktionsfähigen Fenster-Manager.

## 🪐 Die Komponenten
1. **Das Universum (Canvas):** 
   - Eine strahlende, pulsierende Sonne im Zentrum.
   - 12 Planeten (Merkur bis Haumea) mit echten Farben und Umlaufbahnen.
   - Ein funkelnder Sternenhimmel und Galaxie-Hintergrund.
2. **Die Erde & Der Cyborg (Bilder):**
   - `earth.png` als fotorealistischer Hintergrund (mit langsamer Zoom-Animation).
   - `cyborg.png` als lebendige AI-Präsenz im Vordergrund (mit Schwebe-Animation).
   - `logo.png` als Profilbild im Chat.
3. **Das UI (Glassmorphism):**
   - Verschiebbare Fenster (Drag & Drop) für Chat, Dateien, System-Updates und Sonnenkern.
   - Statusleiste mit 6 Farbpunkten für: Schließen, Mikrofon, Lautsprecher, Dateien, Sonne, Updates.
4. **Funktionen:**
   - Echte Sprachausgabe (Text-to-Speech).
   - Echte Spracherkennung (Speech-to-Text über das Mikrofon).
   - System-Logs und Update-Simulation.
